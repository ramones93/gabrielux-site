# Gabriel UX Portfolio

Sitio estático para gabrielux.com.ar.

## Archivos

- `index.html`: estructura y contenido.
- `styles.css`: estilos responsive.
- `script.js`: menú mobile y año dinámico.
- `assets/`: carpeta para imágenes, CV y capturas.

## Deploy recomendado en Cloudflare Pages

1. Subir estos archivos a un repositorio de GitHub.
2. Entrar a Cloudflare > Workers & Pages > Create application > Pages.
3. Conectar el repo.
4. Framework preset: None.
5. Build command: dejar vacío.
6. Output directory: `/`.
7. Agregar custom domain: `gabrielux.com.ar`.

## Pendientes sugeridos

- Reemplazar textos placeholder por casos reales.
- Agregar `/cv.pdf` en la raíz o cambiar el link.
- Agregar capturas de proyectos en `assets/`.
- Agregar favicon y preview social.
