# Gabriel UX Portfolio

Sitio estático para gabrielux.com.ar.

## Cómo editar contenido

La mayoría de los textos se editan desde:

- `content.json`

## Archivos principales

- `index.html`: estructura de la página.
- `styles.css`: estilos responsive.
- `script.js`: carga el contenido desde `content.json`.
- `content.json`: textos, proyectos, links y configuración editable.
- `assets/`: carpeta para imágenes, CV y capturas.
